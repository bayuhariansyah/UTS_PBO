
# APLIKASI KASIR RESTORAN SEDERHANA

## 1. Deskripsi Aplikasi
Aplikasi Kasir Restoran Sederhana merupakan program berbasis Python dengan tampilan Command Line Interface (CLI).

Aplikasi ini digunakan untuk mengelola menu makanan, minuman, pesanan pelanggan, menghitung total harga, dan memeriksa status pesanan.

## 2. Konsep Pemrograman Berorientasi Objek (OOP)

- **Class dan Object:** Digunakan untuk membuat objek menu makanan, minuman, dan pesanan.
- **Attribute dan Method:** Digunakan untuk menyimpan data dan menjalankan fungsi pada setiap class.
- **Constructor:** Digunakan untuk memberikan nilai awal pada objek.
- **Encapsulation:** Menggunakan atribut private dan getter untuk melindungi data.
- **Inheritance:** Class Makanan dan Minuman mewarisi class Menu.
- **Association:** Class Pesanan berhubungan dengan beberapa objek Menu.

## 3. Struktur Class

- Menu: Superclass.
- Makanan: Subclass dari Menu.
- Minuman: Subclass dari Menu.
- Pesanan: Class yang mengelola daftar menu dalam pesanan pelanggan.

## 4. Fitur Aplikasi

1. Menambahkan data menu.
2. Menampilkan data menu.
3. Mencari menu.
4. Mengubah harga menu.
5. Membuat pesanan pelanggan.
6. Menghitung total pembayaran.
7. Memeriksa status pesanan.
8. Keluar dari aplikasi.
